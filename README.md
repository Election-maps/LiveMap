# 📍 WhatsApp Group Live Map Tracker (లైవ్ గ్రూప్ లొకేషన్ ట్రాకర్)

వాట్సాప్ గ్రూప్‌లోని సభ్యులందరూ తమ లైవ్ లొకేషన్‌ను ఒకే మ్యాప్‌లో రియల్-టైమ్‌లో చూడటానికి రూపొందించబడిన వెబ్‌సైట్.

---

## 🌟 ఫీచర్లు (Features)
1. **ఒకే మ్యాప్‌లో అందరి లొకేషన్లు:** గ్రూప్‌లోని సభ్యులందరి రియల్-టైమ్ GPS పొజిషన్లు, కదలికలు ఒకే మ్యాప్‌లో కనిపిస్తాయి.
2. **వాట్సాప్ వన్-క్లిక్ షేర్:** వెబ్‌సైట్ లింక్‌ను నేరుగా వాట్సాప్ గ్రూపులో పంపడానికి షేర్ బటన్.
3. **రూమ్ / గ్రూప్ సిస్టమ్:** ప్రతి వాట్సాప్ గ్రూపుకు ఒక ప్రత్యేకమైన లింక్ (ఉదా: `?room=FriendsTrip`).
4. **లైవ్ వివరాలు:** ప్రతి సభ్యుడి పేరు, వేగం (Speed km/h), GPS ఖచ్చితత్వం (Accuracy ±m).
5. **మ్యాప్ లేయర్స్:** సాధారణ రోడ్ల మ్యాప్ (Street) మరియు గూగుల్ శాటిలైట్ మ్యాప్ (Satellite View) రెండూ అందుబాటులో ఉన్నాయి.
6. **తెలుగు & ఇంగ్లీష్:** స్క్రీన్ పైన ఉన్న బటన్ ద్వారా తెలుగు లేదా ఇంగ్లీష్‌లోకి మార్చుకోవచ్చు.

---

## 🚀 వెంటనే మీ కంప్యూటర్‌లో ఎలా ప్రారంభించాలి? (Local Testing)
1. ఈ ఫోల్డర్‌లోని **`start.bat`** ఫైల్‌పై డబుల్ క్లిక్ చేయండి.
2. వెంటనే మీ బ్రౌజర్‌లో **`http://localhost:8080`** ఓపెన్ అవుతుంది.
3. మీ పేరు నమోదు చేసి **"షేర్ చేయండి" (Share Location)** బటన్ నొక్కండి.

---

## 🌐 వాట్సాప్ గ్రూప్ సభ్యుల కోసం ఇంటర్నెట్‌లో ఉచితంగా లైవ్ చేయడం ఎలా? (Free Hosting)
మొబైల్ ఫోన్లలో GPS లొకేషన్ పనిచేయడానికి బ్రౌజర్‌లకు **HTTPS (SSL)** తప్పనిసరి. దీన్ని 2 నిమిషాల్లో ఉచితంగా GitHub Pages లేదా Netlify లో హోస్ట్ చేయవచ్చు:

### పద్ధతి 1: GitHub Pages (ఉచితం & శాశ్వతం)
1. [GitHub.com](https://github.com) లో కొత్త రిపోజిటరీ (New Repository) క్రియేట్ చేయండి (ఉదా: `live-map`).
2. ఈ ఫోల్డర్‌లోని `index.html` ఫైల్‌ను అందులోకి అప్‌లోడ్ చేయండి.
3. GitHub రిపోజిటరీ **Settings** > **Pages** లోకి వెళ్లి, **Branch: main** సెలెక్ట్ చేసి Save చేయండి.
4. మీకు `https://your-username.github.io/live-map/` అనే ఉచిత లింక్ వస్తుంది.
5. ఆ లింక్‌ను వాట్సాప్ గ్రూపులో షేర్ చేయండి!

### పద్ధతి 2: Netlify Drop (కేవలం 30 సెకన్లు)
1. [app.netlify.com/drop](https://app.netlify.com/drop) ఓపెన్ చేయండి.
2. ఈ `Live track` ఫోల్డర్‌ను డ్రాగ్ చేసి అక్కడ డ్రాప్ చేయండి.
3. వెంటనే మీకు ఒక లైవ్ `https://...` వెబ్‌సైట్ లింక్ లభిస్తుంది!

## 📱 వాట్సాప్ గ్రూప్ సభ్యులు ఎలా వాడాలి?
1. మీరు పంపిన లింక్‌పై గ్రూప్ సభ్యులు క్లిక్ చేస్తారు.
2. తమ పేరు ఎంటర్ చేసి **"లొకేషన్ షేర్ చేయండి"** క్లిక్ చేస్తారు.
3. ఫోన్ స్క్రీన్‌పై బ్రౌజర్ అడిగే **"Allow Location Access"** పర్మిషన్ ఇస్తారు.
4. అంతే! గ్రూప్‌లోని అందరి లొకేషన్లు మ్యాప్‌లో లైవ్‌గా కదులుతూ కనిపిస్తాయి.
