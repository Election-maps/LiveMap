# 📍 శ్రీకాకుళం జిల్లా రూట్ మొబైల్స్ లైవ్ మ్యాప్ ట్రాకర్
### (Srikakulam District Route Mobiles Real-Time Live Map)

**శ్రీకాకుళం జిల్లాలోని 271 పోలీస్ రూట్ మొబైల్స్ (MPTC/ZPTC బందోబస్తు సిబ్బంది) లొకేషన్‌లను వాట్సాప్ గ్రూప్ ద్వారా ఒకే మ్యాప్‌లో రియల్-టైమ్‌లో ట్రాక్ చేసేందుకు రూపొందించబడిన ప్రత్యేక అప్లికేషన్.**

---

## 💡 ముఖ్య గమనిక: వాట్సాప్ లైవ్ లొకేషన్ మరియు ఈ మ్యాప్ ఎలా పనిచేస్తాయి?

1. **వాట్సాప్ అంతర్గత లొకేషన్ పరిమితి:** 
   - వాట్సాప్ చాట్ లోపల షేర్ చేసే లైవ్ లొకేషన్ End-to-End Encrypted (పూర్తి భద్రత) తో ఉంటుంది.
   - వాట్సాప్ వారు ఏ బాహ్య మ్యాప్ లేదా వెబ్‌సైట్‌కు నేరుగా వాట్సాప్ లోపలి లొకేషన్‌ను అందించే API ఇవ్వరు.
2. **మన సిస్టమ్ పరిష్కారం:**
   - ఈ అప్లికేషన్‌లోని **"వాట్సాప్ గ్రూప్ షేర్"** లింక్‌ను వాట్సాప్ గ్రూపులో పంపండి.
   - సిబ్బంది ఆ లింక్ క్లిక్ చేసి తమ **పోలీస్ స్టేషన్** మరియు **రూట్ నెంబర్ (RM-1, RM-2, ...)** ఎంచుకుని **"లైవ్ లొకేషన్ ప్రారంభించండి"** నొక్కితే చాలు!
   - వెంటనే కంట్రోల్ రూమ్ స్క్రీన్‌పై వారి కదలికలు, వేగం (Speed km/h), GPS ఖచ్చితత్వంతో సహా లైవ్‌గా కనిపిస్తాయి.

---

## 🌟 ముఖ్య ఫీచర్లు (Features)

1. **271 రూట్ మొబైల్స్ డేటాబేస్:**
   - `Route mobiles data of Srikakulam Dist.xlsx` ఎక్సెల్ షీట్ లోని మొత్తం 271 మంది ఆఫీసర్ల వివరాలు (PS, Route No, Officer Name, Phone Number) పూర్తిగా అనుసంధానించబడ్డాయి.
2. **శ్రీకాకుళం జిల్లా కేంద్రీకృత మ్యాప్:**
   - మ్యాప్ నేరుగా శ్రీకాకుళం జిల్లా (ఇచ్ఛాపురం నుండి రణస్థలం, లావేరు, పాతపట్నం, హిరమండలం వరకు) కేంద్రీకృతమై ఉంటుంది.
3. **కంట్రోల్ రూమ్ డైరెక్టరీ & స్టేటస్:**
   - మొత్తం 271 రూట్లలో ఎన్ని లైవ్‌లో ఉన్నాయి (🟢 Live), ఎన్ని ఇంకా రాలేదు (⚪ Offline) స్పష్టంగా తెలుస్తుంది.
   - పోలీస్ స్టేషన్ల వారీగా ఫిల్టర్ చేసుకోవచ్చు లేదా ఆఫీసర్ పేరు/ఫోన్ నెంబర్‌తో వెతకవచ్చు.
4. **ఆఫ్‌లైన్ ఆఫీసర్లకు 1-క్లిక్ వాట్సాప్ లింక్:**
   - ఇంకా లొకేషన్ షేర్ చేయని ఆఫీసర్లకు కంట్రోల్ రూమ్ నుండి నేరుగా వాట్సాప్ మెసేజ్ బటన్ నొక్కితే, వారికి ప్రత్యేకమైన డైరెక్ట్ లింక్ వెళ్తుంది.
5. **మొబైల్ బ్యాక్‌గ్రౌండ్ కీప్-అలైవ్ (Keep-Alive):**
   - స్క్రీన్ లాక్ అయినా లేదా ఫోన్ హోమ్ బటన్ నొక్కి వాట్సాప్ చూస్తున్నా బ్యాక్‌గ్రౌండ్‌లో లొకేషన్ నిరంతరం అప్‌డేట్ అవుతుంది.
6. **మ్యాప్ లేయర్లు:**
   - సాధారణ రోడ్ల మ్యాప్ (Street View) మరియు గూగుల్ శాటిలైట్ మ్యాప్ (Satellite View) రెండూ అందుబాటులో ఉన్నాయి.
7. **ద్విభాషా సౌలభ్యం (Telugu & English):**
   - స్క్రీన్ పైన ఉన్న బటన్ ద్వారా తెలుగు లేదా ఇంగ్లీష్‌లోకి సులభంగా మార్చుకోవచ్చు.

## 🚀 కంప్యూటర్ / కంట్రోల్ రూమ్‌లో ప్రారంభించడం ఎలా? (Local Run)

1. ఈ ఫోల్డర్‌లోని **`start.bat`** ఫైల్‌పై డబుల్ క్లిక్ చేయండి.
2. బ్రౌజర్‌లో కంట్రోల్ రూమ్ లైవ్ మ్యాప్ ఓపెన్ అవుతుంది:
   ```
   http://localhost:8080/
   ```
3. స్క్రీన్ పైన ఉన్న **"గ్రూప్ షేర్" (WhatsApp Group Share)** బటన్ నొక్కి వాట్సాప్ గ్రూపులో లింక్ షేర్ చేయండి.

## 🌐 ఫీల్డ్ ఆఫీసర్ల కోసం ఇంటర్నెట్‌లో లైవ్ చేయడం ఎలా? (Free HTTPS Hosting)

మొబైల్ ఫోన్ల నుండి GPS లొకేషన్ సరిగ్గా పంపడానికి బ్రౌజర్‌లకు **HTTPS (SSL)** లింక్ అవసరం. దీన్ని 2 నిమిషాల్లో ఉచితంగా లైవ్ చేసుకోవచ్చు:

### పద్ధతి 1: Netlify Drop (కేవలం 1 నిమిషం)
1. [app.netlify.com/drop](https://app.netlify.com/drop) ఓపెన్ చేయండి.
2. మీ కంప్యూటర్‌లోని ఈ **`Live track`** ఫోల్డర్‌ను డ్రాగ్ చేసి అక్కడ డ్రాప్ చేయండి.
3. వెంటనే మీకు ఒక ఉచిత లైవ్ లింక్ (ఉదా: `https://srikakulam-police-tracker.netlify.app/`) వస్తుంది.
4. ఆ లింక్‌ను వాట్సాప్ గ్రూపులో పంపండి!

### పద్ధతి 2: GitHub Pages (శాశ్వతం & ఉచితం)
1. GitHub.com లో కొత్త రిపోజిటరీ క్రియేట్ చేయండి.
2. ఈ ఫోల్డర్‌లోని ఫైల్స్ (`index.html`, `route_mobiles_data.js`, `route_mobiles.json`) అప్‌లోడ్ చేయండి.
3. **Settings > Pages** లోకి వెళ్లి Main బ్రాంచ్ సేవ్ చేయండి.
4. వచ్చే `https://your-name.github.io/repository-name/` లింక్‌ను వాడండి.

## 📱 ఫీల్డ్ ఆఫీసర్లు (రూట్ మొబైల్ సిబ్బంది) ఎలా ఉపయోగించాలి?

1. వాట్సాప్ గ్రూప్‌లో వచ్చిన లింక్‌పై క్లిక్ చేస్తారు.
2. తమ **పోలీస్ స్టేషన్** మరియు **రూట్ నెంబర్ (ఉదా: RM-1)** సెలెక్ట్ చేస్తారు (వారి పేరు, ఫోన్ ఆటోమేటిక్‌గా వస్తాయి).
3. **"లైవ్ లొకేషన్ ప్రారంభించండి"** బటన్ నొక్కి, బ్రౌజర్ అడిగే **"Allow Location"** పర్మిషన్ ఇస్తారు.
4. **హోమ్ బటన్** నొక్కి మొబైల్ వాడవచ్చు. వారి లొకేషన్ నిరంతరం కంట్రోల్ రూమ్ మ్యాప్‌లో లైవ్‌గా ట్రాక్ అవుతుంది.
